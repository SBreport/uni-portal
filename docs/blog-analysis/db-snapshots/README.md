# 블로그 분석 DB 스냅샷

운영 웹에서 내려받은 블로그 분석용 DB 보관 공간이다.

## 보관 규칙

- 프로젝트별 하위 폴더를 만든다.
- 다운로드한 원본 DB 파일명을 유지한다.
- 각 프로젝트의 `db_source.md`에 보관 위치, 해시, row 수, 최신 발행일을 기록한다.
- 새 분석을 시작할 때 기존 스냅샷을 덮어쓰지 않는다.
