# 2026H1 최적블로그 실패율 진단 기획서

작성일: 2026-06-30  
프로젝트 위치: `docs/blog-analysis/projects/2026H1_optimal_blog_youand_local/`  
공통 기준: `docs/blog-analysis/standards/블로그분석_공통기준.md`
DB 기준: `docs/blog-analysis/projects/2026H1_optimal_blog_youand_local/db_source.md`

## 1. 목적

2026년 1~6월에 발행된 최적블로그 원고의 실패율을 진단한다.

이번 프로젝트의 핵심 질문은 다음과 같다.

- 5~6월에 실패율이 실제로 상승했는가?
- 실패율 상승이 유앤/로컬 중 어디에서 먼저 발생했는가?
- 계정 문제인지, 지점 문제인지, 키워드/지역 난이도 문제인지 분리할 수 있는가?
- 다음 발행 전략에서 줄여야 할 계정과 우선 점검해야 할 지점은 어디인가?

## 2. 분석 범위

- 기간: 2026-01-01 ~ 2026-06-30
- 월 기준: 발행일 `published_at`
- 분석 대상: 최적블로그 계열 원고
- 분석 그룹: 유앤, 로컬

## 3. 분석 대상 기준

최적블로그 분석 대상은 다음 기준으로 확정한다.

- 포함: `유앤 최적`, `유앤최적`, `로컬최적배포`, `로컬최적`, `최적블로그`
- 제외: `준최`, `NB`
- 보정 포함: `유앤평택 최적6` 1건
  - 원본종류는 `홍보성글`로 들어왔지만 콘텐츠번호에 최적 발행 근거가 있어 데이터 오류로 판단했다.

이번 프로젝트 기준 최종 대상은 다음과 같다.

| 구분 | 건수 | 처리 |
| --- | ---: | --- |
| 원 추출 대상 | 3,474 | 초기 상세 CSV 기준 |
| 준최/NB | 68 | 제외 |
| 홍보성글 오분류 | 1 | 보정 포함 |
| 최종 분석 대상 | 3,406 | HTML 리포트 기준 |

## 4. 지표 기준

이번 리포트는 성공률보다 실패율을 중심으로 본다.

- 성공: 순위 1~10
- 실패: 순위 0, 빈값, 11위 이상
- 미노출: 순위 0 또는 빈값
- 상위10밖: 순위 11 이상

기본 표시 지표는 다음으로 압축한다.

- 발행건
- 실패수
- 실패율
- 미노출
- 상위10밖

성공수와 성공률은 실패율의 반대 지표이므로 기본 화면에서는 제외한다.

## 5. 지점 정규화

유앤은 43개 활성 지점 마스터를 기준으로 본다.

중요한 발견은 `프로젝트지점`이 비어 있는 유앤 원고가 많았다는 점이다. 따라서 유앤 지점 분석은 `발행지점`을 우선 파싱하도록 정리했다.

보정 예시는 다음과 같다.

- `유앤건대 최적1` -> `건대`
- `유앤목포 최적1` -> `목포`
- `유앤미금` -> `분당미금`
- `유앤검단` -> `인천검단`
- `유앤배곧` -> `시흥배곧`
- `유앤홍대` -> `홍대신촌`
- `유앤의정부 최` -> `의정부`

이 보정 후 유앤 지점은 43/43개가 리포트에 반영된다.

## 6. 현재 웹 리포트 구조

`optimal_blog_2026H1_report.html`은 다음 탭으로 구성한다.

- 기간 요약
- 유앤 상세
- 로컬 상세
- 계정별 진단

계정별 진단 탭 내부에는 유앤/로컬 스위치를 둔다.

- 유앤 계정별 실패율
- 로컬 계정별 실패율

월별 표는 성공률/실패율/발행건을 나열하지 않고, 월별 실패율 한 칸에 `실패율`과 `실패수 / 발행건`만 표시한다.
