# 기준표 외 데이터 진단

## 기준

- 분석 기간: 2026-01-01 ~ 2026-06-30
- 기준표: 2026년 6월 운영 지점 현황
- 메인 보고서에는 기준표와 매칭된 지점만 포함한다.
- 기준표에 없는 데이터는 `기준표 외 데이터`로 분리한다.

## 판단

- `프라임`, `프라임 6-*`, `디자인 브블 *_리라이팅`은 정리 규칙 보완 후 기준표 매칭 데이터로 이동했다.
- `365봄치과`는 계약 유지 중이므로 기준표에 포함했다.
- `용인터미널퍼스트치과`는 2026년 2월까지 계약이지만 기간 내 데이터가 있으므로 기준표에 포함했다.
- `천지세무`, `세무법인 현답`은 병의원은 아니지만 블로그 성과 분석 대상이므로 기준표에 포함했다.
- 미러링 데이터는 블로그 성과 진단과 목적이 다르므로 메인 보고서에서 제외한다.
- 미러링 제외 후 남은 기준표 외 데이터는 `하남미사 막글 작업` 1건뿐이며, 제외 유지가 적절하다.
