# 분석 대상 지점 수 감사

## 질문

사용자가 제시한 후보 지점은 40개이며, 여기서 bioadd lab 7개 지점을 제외하면 33개가 된다. 그런데 현재 보고서의 분석 대상 지점은 31개로 표시된다.

## 결론

현재 31개는 보고서 기준표와 실제 2026년 1~6월 블로그 데이터가 매칭된 지점 수다.

사용자가 제시한 33개 후보와 현재 보고서 31개는 같은 목록에서 2개만 빠진 구조가 아니다. 두 목록의 기준이 일부 다르다.

## 사용자 제시 목록 중 데이터가 확인되지 않은 지점

아래 지점은 2026년 1~6월 `blog_posts`에서 지점명/프로젝트명/원고명/키워드 기준으로 직접 매칭되는 데이터가 0건이다.

| 지점 | 확인 결과 |
|---|---:|
| 연세진치과 | 0건 |
| 홍준기 원장님 | 0건 |
| 블루비뇨기과 강남 | 0건 |
| 블루비뇨기과 잠실 | 0건 |

| 블루비뇨기과 판교 | 0건 |

전체 DB에서 `블루` 검색 시 유앤아이 시술 키워드 데이터만 확인되며, 블루비뇨기과 지점 데이터는 확인되지 않았다.

## 현재 보고서 기준표에 포함된 추가 지점/프로젝트

아래 항목은 사용자가 직전에 제시한 33개 후보에는 없지만, 이전 확인 과정에서 포함하기로 한 데이터이거나 기존 운영 데이터에 존재해 현재 보고서 기준표에 포함되어 있다.

| 365봄치과 | 계약 유지 중으로 확인되어 포함 |
| 용인터미널퍼스트치과 | 2026년 2월까지 계약, 기간 내 데이터가 있어 포함 |

| 충주연세세브란스치과 | 2026년 1~6월 발행 데이터 존재 |

## 판단

- 33개 후보 중 8개는 현재 DB에서 지점 데이터가 확인되지 않는다.
- 현재 보고서에는 사용자 후보에 없던 6개 항목이 포함되어 있다.
- 따라서 현재 31개는 단순 누락이라기보다, `사용자 후보 기준`과 `현재 DB/운영 기준표`가 서로 다르기 때문에 생긴 차이다.
