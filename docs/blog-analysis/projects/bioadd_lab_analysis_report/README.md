# bioadd lab 분석 보고서

bioadd lab 타겟 지점의 블로그 발행 성과를 일반 블로그/최적 블로그 기준으로 나누어 분석하는 프로젝트다.

## 보고서 표기 기준

- 일반 블로그: 브랜드 블로그 발행 데이터
- 최적 블로그: 최적 블로그 발행 데이터
- 실패: 미노출 또는 11위 이상

## 현재 산출물

- `bioadd_lab_report.html`: 웹페이지 리포트
- `bioadd_lab_analysis_plan.md`: 데이터 확보 및 기준 초안
- `bioadd_lab_target_detail.csv`: 타겟 상세 데이터
- `bioadd_lab_target_summary.csv`: 지점별 요약
- `bioadd_lab_monthly_summary.csv`: 월별 요약

## 기준 DB

현재 로컬 반영 DB `data/equipment.db`를 기준으로 1차 데이터를 확보했다. DB 출처와 갱신 기준은 `../../standards/블로그분석_DB관리기준.md`를 따른다.
