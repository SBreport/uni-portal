## 3. 보고서 표기 기준

- 일반 블로그: 브랜드 블로그 발행 데이터
- 최적 블로그: 최적 블로그 발행 데이터
- 성공: 상위10 진입
- 미달성: 미노출 또는 11위 이상

## 4. 데이터 추출 기준

- 최적 블로그 데이터: `blog_channel = opt` 또는 `post_type_main = 최적` 또는 `post_type`에 최적 포함
- 일반 블로그 데이터: 최적 블로그가 아닌 브랜드 블로그 발행 데이터
- 제외: `서비스` 카테고리 및 서비스 기자단 발행 데이터
- 지점 매칭: `branch_name`, `content_number`, `project_branch`, `project`에서 지점명/약칭으로 매칭
