## 3. 현재 주의점

- `셀365웰정형외과의원`은 현재 분석 DB에 타겟명 기준 데이터가 없다.
- `노블와이`, `온우의원`, `청담위아르` 등 일부 브블 데이터는 `post_type_main`이 빈값이다. 성과 분석에서는 발행 구분을 우선 `blog_channel`/최적 여부로 판단한다.
- `아도의원`은 짧은 별칭 `아도`가 다른 제목/키워드에 섞일 위험이 있어 구조 필드만 사용한다.
