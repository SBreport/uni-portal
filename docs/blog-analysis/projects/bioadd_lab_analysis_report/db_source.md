## 이번 프로젝트 추출 기준

- 보고서 타겟 지점 7개
- 매칭 필드: `branch_name`, `content_number`, `project_branch`, `project`
- 일반 블로그: 브랜드 블로그 발행 데이터
- 최적 블로그: 최적 블로그 발행 데이터
- 실패: 미노출 또는 11위 이상

내부 추출에서는 최적 블로그 데이터를 `blog_channel = opt` 또는 `post_type_main = 최적` 또는 `post_type`에 최적이 포함된 데이터로 판정한다.
